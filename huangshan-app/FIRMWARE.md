# Codex额度 黄山派固件 0.6.5

适用板级：`sf32lb52-lchspi-ulp`，标配390×450 AMOLED。仅在对应黄山派硬件上使用，其他板卡/屏幕未验证。不是小米手环RPK。固件不含用户配对数据、访问令牌或原设备备份。

## 刷写

准备Windows、SiFli官方`sftool`（本机验证版本0.1.12）和USB串口连接，确认设备对应的COM端口。解压ZIP，在解压文件夹中打开PowerShell运行：

```powershell
.\Flash.ps1 -Port COM4 -SfTool C:\path\to\sftool.exe
```

用实际端口和工具路径替换示例。脚本先校验三个镜像的SHA-256，再备份将覆盖的区域到新建的`backup-*`目录，核对备份长度后刷写并回读校验。不整片擦除，不写BLE配对分区。保留备份文件夹，升级时不要覆盖或删除。

| 镜像 | 地址 |
| --- | --- |
| ftab.bin | 0x12000000 |
| bootloader.bin | 0x12010000 |
| main.bin | 0x12020000 |

## 连接与操作

安装同版本Windows安装包，在系统蓝牙设置添加`CodexQuota-HSPI`，输入屏幕显示的6位PIN，然后在Codex额度托盘菜单启用“黄山派蓝牙同步”。已有配对可自动恢复。Windows需要有可用额度来源；无需Android手机。

仅周额度显示单圈，两个窗口都可用时显示双圈。KEY2短按切换同心与数据行布局；双窗口时触摸切换中央额度。红色低于20%，黄色20–49%，绿色50%及以上；倒计时使用xhxxm/xdxxh。

纯黑背景、30%亮度，每60秒最大±2px位移。持续断线180秒后全黑并将亮度设为0，保持触摸与BLE工作。无有效包45秒判定断线。触摸、KEY2和有效BLE包均可唤醒；首次触摸/按键只唤醒，离线唤醒后重新计时。缓存只保留在RAM，断电需重新同步。

## 验证范围

当前候选已通过用户真机验收，包括单圈、KEY2布局切换和OLED保护/唤醒。真实账号仅提供周窗口；双窗口触摸仍待对应套餐验证。闪存备份和写入命令与本机工具一致；发布包Flash.ps1仅做静态检查，未再次写入设备。未测量面板电流或寿命。
