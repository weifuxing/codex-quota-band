# UI设计规则

Windows保持轻量原生托盘，项目图标统一，普通界面只用标题、正文、辅助文字三档，不引入手机配对页面。连接说明使用原生对话框；托盘菜单在实际运行中检查。

黄山派390×450，纯黑#000000背景，文字#F2F6F7/辅助#B3C0C5，轨道#27373E，状态胶囊#202E34。字号18/22/60，100%使用紧凑数字档。保留安全区，±2px位移不裁切文字与触摸区域。

额度低于20%红#FFB4AB，20–49%黄#FFC968，50%及以上绿#72D6A6；未知灰。缓存和离线只改变同步胶囊，不把整页或额度染黄。颜色同时伴随文字。示意图明确标为示例数据，不冒充真机照片。
