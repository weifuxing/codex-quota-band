# 安全与隐私

Windows只在本机读取现有Codex访问令牌，低频请求官方额度接口。令牌只驻留进程内存，不写日志、缓存、诊断或BLE。额度缓存不含凭据。

Windows只连接已配对且名称符合CodexQuota-HSPI的设备；多个匹配设备时拒绝歧义连接。GATT写入要求认证与加密，显示PIN配对。BLE摘要只含额度、重置、确认时间和状态，不含任务、提示词、回复、命令、路径或账号内容。

main没有LAN/WSS服务器、手机配对或云端中转。无遥测、广告和自动崩溃上报。升级迁移只删除有--owner codex-quota标记的旧Hook，保留其他Hook并先做本地备份；不收集该配置内容。

原固件备份与BLE配对数据不公开。发布只包含通用镜像、工具脚本、说明与校验值。
